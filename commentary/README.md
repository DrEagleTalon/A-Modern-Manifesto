# Commentary

Footnotes, explanations, background, application, critique and later theory on the works in this library, written by each tradition in its own files.

```
commentary/<tradition>/<work-id>.yaml    e.g. commentary/anarchist-communist/communist-manifesto.yaml
commentary/<tradition>/_library.yaml     entries about several works at once
commentary/_template.yaml                copy this to start
```

Tradition slugs are in `../traditions.yaml`. Read `../docs/commentary-guide.md` before writing. Everything here is checked by `scripts/validate.py` and shown in the reader when "Commentary" is switched on.
