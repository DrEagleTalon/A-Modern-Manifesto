# Renderings

Alternative modern translations, by tradition, of the verses where a tradition would translate differently from the shared modern draft in `works/`.

```
renderings/<tradition>/<work-id>.yaml    e.g. renderings/maoist/communist-manifesto.yaml
renderings/_template.yaml                copy this to start
```

List only the verses that differ, and say why. Read `../docs/commentary-guide.md`. Shown in the reader when "Rendering" is switched on.
